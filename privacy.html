Privacy policy

VikerStudios Uploader. Last updated: 7 October 2026.

Who we are

VikerStudios publishes a maze game and runs the YouTube channel @VikerStudios. VikerStudios Uploader is the internal tool we use to upload our own videos to that channel.

What the tool does

The tool uploads solution videos that we created to the VikerStudios channel. It is used only by the VikerStudios developer. It is not offered to the public and has no sign-in for visitors.

Google user data we access

When the developer authorizes the tool, it asks for one permission from the Google account that owns the channel: youtube.upload, which allows uploading videos to the channel. The tool does not read, download or change anything else in the account or on the channel.

How we store it

The authorization token is kept as an encrypted secret in a private code repository and is used only to run the uploads. We don't collect personal data from anyone else, and we don't use analytics or advertising trackers on this site.

Sharing

We don't sell, share or transfer Google user data to anyone.

Google API Services User Data Policy

The use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google account permissions page. Once it is revoked, the tool can no longer upload to the channel.

Contact

Changes

If we change how the tool uses Google data, we will update this page and its date.
